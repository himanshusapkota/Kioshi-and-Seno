# Kioshi and Seno

A small visual novel made with Ren'Py.

**Kioshi and Seno** is a simple school-life story about two students, their conversations, and the choices that can change how their relationship goes.

## About

I made this project to learn more about Ren'Py and visual novel development.

The game focuses mainly on dialogue, character expressions, and choices. The story can change depending on what the player chooses.

## Characters

### Kioshi

Kioshi is a school boy and one of the main characters in the story. He is involved in the conversations and choices that shape the story.

### Seno

Seno is a school girl and the other main character. Her conversations with Kioshi are an important part of the story.




## Made With

- Ren'Py
- PNG assets
- Visual novel dialogue and choice system

## How to Run

1. Download and install Ren'Py.
2. Download or clone this repository.
3. Open the project in the Ren'Py Launcher.
4. Select the project.
5. Click **Launch Project**.
